# Kubernetes Threat Model (ATS044)

Kubernetes and Cloud Native Associate (KCSA) — Kubernetes Threat Model, 16% of the published curriculum. This course is part of ATP009.

Concept lessons explain each official objective through concrete examples, diagrams and scenario reasoning. Every section begins with an introduction, and every module ends with a summary. Reusable YAML question banks include the correct answer, option feedback and learning-objective mapping.

## Authoring Status

First content draft for review. Each section has two modules with playgrounds, a graded lab per module, a capstone lab and a knowledge check. All labs and playgrounds are untested: they passed `astrona validate` and shell syntax checks only and have never run on a cluster. A kind cluster with the astrona tool is needed to run them. Technical sections and the ATP009 registration remain draft until the maintainer approves publication.
