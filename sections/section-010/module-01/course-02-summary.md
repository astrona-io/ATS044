# Summary

Threat modelling identifies assets, actors, entry points and transitions between trust assumptions. Requests cross network, identity, application, data and execution boundaries that need different controls.

Supply chain and administrative authority belong in the same model. Explicit assumptions and failure consequences connect threats to prevention, observation and recovery rather than relying on an unstructured list of security products.
