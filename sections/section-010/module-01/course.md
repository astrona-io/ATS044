# Trust Boundaries And Security Data Flow

This module develops the reasoning needed to identify assets, actors and entry points in a Kubernetes design.

## Learning Goals

- Identify assets, actors and entry points in a Kubernetes design.
- Trace a request across network, identity and execution boundaries.
- Distinguish trusted control components from untrusted workload inputs.
- Relate each boundary to preventive and detective controls.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
