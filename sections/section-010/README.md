# Kubernetes Trust Boundaries and Data Flow

This section teaches trust boundaries and security data flow. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Trust Boundaries And Security Data Flow and Trust Boundaries And Request Data Flow. Each module has a landing page, deep-dive parts with hands-on steps in a playground, a graded lab and a summary. The section ends with a capstone lab that combines the skills of both modules and a knowledge check.

## Learning Outcomes

- Identify assets, actors and entry points in a Kubernetes design.
- Trace a request across network, identity and execution boundaries.
- Distinguish trusted control components from untrusted workload inputs.
- Relate each boundary to preventive and detective controls.
