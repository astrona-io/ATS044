# Summary

Application compromise initially uses the process's available data, credentials and connection paths. Least privilege limits direct impact across Kubernetes and external services. Escape is a distinct crossing into broader execution authority.

Code defenses reduce causes while runtime and network containment reduce selected consequences. Recovery must restore trustworthy inputs and assess durable effects, with stronger infrastructure restoration when host trust was lost.
