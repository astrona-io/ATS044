# Malicious Code Execution and Compromised Applications in Containers

This section teaches compromised application consequences. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Compromised Application Consequences and Containing And Recovering A Compromised Workload. Each module has a landing page, deep-dive parts with hands-on steps in a playground, a graded lab and a summary. The section ends with a capstone lab that combines the skills of both modules and a knowledge check.

## Learning Outcomes

- Distinguish application compromise from container escape.
- Trace available credentials, mounts and network paths after compromise.
- Relate code defenses and containment to different outcomes.
- Describe evidence and trusted recovery for an affected workload.
