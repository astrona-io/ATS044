# Persistence

This section teaches persistence after workload compromise. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Persistence After Workload Compromise and Persistence Through Credentials And Nodes. Each module has a landing page, deep-dive parts with hands-on steps in a playground, a graded lab and a summary. The section ends with a capstone lab that combines the skills of both modules and a knowledge check.

## Learning Outcomes

- Distinguish attacker persistence from ordinary application storage persistence.
- Identify durable configuration, identity and data changes that survive Pod deletion.
- Relate reconciliation to trusted and compromised desired state.
- Describe recovery that restores inputs and revokes authority.
