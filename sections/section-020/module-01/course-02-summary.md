# Summary

Unwanted persistence can reside in controller templates, repositories, credentials, host state or application data. These lifecycles differ from a disposable container and can survive replacement.

Recovery restores trusted inputs and authority sources, revokes exposure and assesses durable changes. Reconciliation is helpful only when its desired state is trustworthy, and a new object identity does not independently establish a clean environment.
