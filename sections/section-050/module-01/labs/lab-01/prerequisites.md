# Prerequisites

- The `astrona` command-line tool, installed and working (`astrona check` passes).
- A container engine that kind can use (Podman or Docker) with about 3 GiB of free memory.
- `kubectl`.
- The reading of this module, so you know the objects and the commands.

The lab starts a kind cluster (Kubernetes 1.35) with the Starfleet workloads in `starfleet` and `outpost`. The commands to start and grade it are in the README of this folder.
