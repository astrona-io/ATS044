# Network Attackers And Peer Trust

This module develops the reasoning needed to identify disclosure, tampering and impersonation threats along a request path.

## Learning Goals

- Identify disclosure, tampering and impersonation threats along a request path.
- Distinguish reachability restriction from transport identity protection.
- Explain certificate verification and encrypted-hop boundaries.
- Relate network evidence to application authorization.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
