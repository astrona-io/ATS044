# Denial of Service

This section teaches denial of service and shared capacity. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Bounding Resource Consumption and Protecting The API Server And Applications. Each module has a landing page, deep-dive parts with hands-on steps in a playground, a graded lab and a summary. The section ends with a capstone lab that combines the skills of both modules and a knowledge check.

## Learning Outcomes

- Identify API, node and application availability assets.
- Compare requests, limits, quotas and rate controls.
- Explain overload amplification through retries and dependencies.
- Relate recovery capacity and evidence to service availability.
