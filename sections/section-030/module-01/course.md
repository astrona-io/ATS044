# Denial Of Service And Shared Capacity

This module develops the reasoning needed to identify API, node and application availability assets.

## Learning Goals

- Identify API, node and application availability assets.
- Compare requests, limits, quotas and rate controls.
- Explain overload amplification through retries and dependencies.
- Relate recovery capacity and evidence to service availability.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
