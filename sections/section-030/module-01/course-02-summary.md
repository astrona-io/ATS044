# Summary

Availability threats can affect API processing, admitted objects, node resources and application dependencies. Requests, runtime limits, quotas and rate or concurrency controls constrain different kinds of demand.

Scaling requires compatible capacity and can amplify a fixed bottleneck. Diagnose the limiting resource, control retry pressure and maintain suitable recovery capacity. A protected container alone does not guarantee the whole service remains available.
