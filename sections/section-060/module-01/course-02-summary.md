# Summary

Sensitive data can cross API, process, diagnostic, backup and artifact boundaries. Each copy and reader needs appropriate protection. Indirect permissions can expose data even when direct Secret read access is absent.

Revocation and rotation must update the issuer and consumers, while past disclosure cannot be undone merely by deleting the current value. Data-specific authorization remains necessary for application operations carried by broad service identities.
