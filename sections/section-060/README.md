# Access to Sensitive Data

This section teaches sensitive data access paths. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Sensitive Data Access Paths and Limiting And Recovering From Disclosure. Each module has a landing page, deep-dive parts with hands-on steps in a playground, a graded lab and a summary. The section ends with a capstone lab that combines the skills of both modules and a knowledge check.

## Learning Outcomes

- Identify sensitive data in live resources, mounted files and retained copies.
- Distinguish encoding, encryption and authorized plaintext access.
- Trace diagnostic and indirect permission exposure.
- Describe revocation and recovery after credential disclosure.
